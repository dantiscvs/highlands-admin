Participant avatar for packing/task checklists, ledger, sharing panel.

```jsx
<AvatarChip name="Mira Kohl" organizer />
<AvatarGroup names={["Mira Kohl", "Tom Reyes", "Nadia Bloom"]} />
```

Color is deterministically hashed from the name across the 5 activity hues (kept for visual rhythm, not semantic meaning here). Organizer dot uses the terracotta accent as its one "second brand moment".

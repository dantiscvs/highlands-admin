Button for all admin-panel actions, from primary CTAs to dense inline row actions.

```jsx
<Button variant="primary">Save trip</Button>
<Button variant="secondary" size="sm">Cancel</Button>
<Button variant="danger">Delete day</Button>
<Button variant="ghost" size="sm">Dismiss</Button>
```

Variants: primary (filled trail green), secondary (outline, neutral surfaces), danger (filled brick red, confirmations), ghost (text-only, toolbar/row-level actions). Sizes: md default, sm for dense contexts (table toolbars, drawer footers). Disabled halves opacity and disables all interaction states.

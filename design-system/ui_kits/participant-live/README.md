# Participant Live Page UI kit

Mobile-first, read-only, light-only page a rider glances at mid-ride. Uses the `.participant-theme`
token scope from `tokens/colors.css` — larger type floor, higher-contrast surfaces, fewer states
than the admin panel (no editing, no dark mode, no dense grid).

Shows: day header with the three key stats, a live "rider is at" callout, a stop-by-stop timeline
(passed / now / upcoming), and tonight's accommodation card.

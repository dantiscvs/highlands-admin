# Admin Panel UI kit

Interactive click-through of the organizer-facing admin panel: sidebar nav (10 sections), Overview
(stat cards + readiness + quick links), a dense Day-by-day grid, a slide-in Drawer for per-day detail,
Accommodation cards, Packing checklist, Expense ledger, Sights empty state, Readiness list, Sharing
panel (visibility toggles + tracking provider status), and the Import review diff-row queue.

Click any sidebar item to switch sections; click a Day-by-day row to open the detail drawer.
